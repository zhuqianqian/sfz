# 顺风账

一个不需要后端的移动端 PWA，用于记录顺风车收入、里程、平台和乘客出行次数。

## 本地预览

在本目录运行 python3 -m http.server 8080，然后访问 http://localhost:8080。

## 安装到 iPhone

PWA 必须通过 HTTPS 地址打开一次，Safari 才能把它作为可离线 App 安装。把整个目录放到任意静态 HTTPS 空间后：

1. 用 iPhone Safari 打开地址。
2. 点“分享”。
3. 选择“添加到主屏幕”。

安装后，页面资源会离线缓存；所有订单数据都只保存在该 iPhone 的浏览器本地存储中。建议定期从“统计 → 导出”下载 CSV 备份。清除 Safari 网站数据会同时删除订单记录。
